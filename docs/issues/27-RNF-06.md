# RNF-06 · Mantenibilidad y calidad del código
<!-- etiquetas: requerimiento no funcional, historia de usuario, estado: hecho -->

## Historia de usuario

**Como** desarrollador del proyecto, **quiero** un código organizado, documentado y con pruebas automáticas, **para** cambiarlo sin romper lo que funciona.

## Descripción

Backend Spring Boot en capas (controlador, servicio, repositorio) organizado por módulo, con catálogo de patrones de diseño (docs/DesignPatterns.md) y migraciones Flyway. Pruebas automáticas: backend con JUnit (H2), frontend con node:test, y el firmware del medidor con pruebas en el computador; GitHub Actions las ejecuta.

## Criterios de aceptación

- [x] Las pruebas automáticas pasan antes de publicar.
- [x] Cada patrón de diseño documentado indica su función y su prueba.
- [x] El README explica cómo instalar, configurar y desplegar.
